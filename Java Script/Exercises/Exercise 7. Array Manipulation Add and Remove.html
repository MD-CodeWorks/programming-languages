Exercise 7. Array Manipulation: Add and Remove

Practice Problem

Create an array of 5 fruits. Add a new fruit ("fig") to the end of the array, then remove the second fruit (at index 1).

Exercise Purpose
This exercise teaches “Dynamic Collection Management.” In JavaScript, arrays serve the role of ordered lists. Arrays are rarely static; being able to modify, expand, and prune them is essential for handling data like shopping carts, user lists, or inventory systems.
Given Input
let fruits = ["apple", "banana", "cherry", "date", "elderberry"];
Expected Output
["apple", "cherry", "date", "elderberry", "fig"]

* Note: JavaScript handles ordered lists using Arrays.
