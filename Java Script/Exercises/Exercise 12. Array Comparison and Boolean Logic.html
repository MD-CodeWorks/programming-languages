Exercise 12. Array Comparison and Boolean Logic

Aug-12-2026 | 10:23 AM

Practice Problem

Write a function to return true if the first and last number of a given array is the same. If the numbers are different, return false.

Exercise Purpose

This exercise introduces “Collection Indexing” and “Boolean Flags.” Comparing data structure boundaries is common in pattern matching and data integrity checks.

Given Input

const numbers_x = [10, 20, 30, 40, 10]; const numbers_y = [75, 65, 35, 75, 30];

Expected Output

Given array: [75, 65, 35, 75, 30] | result is false Given array: [10, 20, 30, 40, 10] | result is true
