Exercise 11. Removing Duplicates from an Array

Aug-11-2026 | 01:53 PM

Practice Problem

Write a script that takes an array containing duplicate items and returns a new array with only unique elements.

Exercise Purpose

This exercise teaches “Data De-duplication.” In real-world web development and data processing, datasets are often “messy” with repeating entries. Mastering the conversion between Arrays (which allow duplicates) and Sets (which store only unique values) or filtering techniques is key to cleaning data efficiently.

Given Input

const data = [1, 2, 2, 3, 4, 4, 4, 5];

Expected Output

Unique Element: [1, 2, 3, 4, 5]
