Exercise 5. Variable Swapping In-Place Method

Practice Problem: Write a program to swap the values of two variables, a and b, without using a third temporary variable.

Exercise Purpose: This exercise will help you learn about memory efficiency and JavaScript’s modern Array Destructuring Assignment feature. In older approaches or traditional languages, you often need a temporary variable to swap values safely. In JavaScript (ES6+), you can swap values in one line cleanly using array destructuring syntax, or using arithmetic operations.

Given Input:
let a = 5;
let b = 10;
Expected Output:
Before Swap: a = 5, b = 10
After Swap: a = 10, b = 5
