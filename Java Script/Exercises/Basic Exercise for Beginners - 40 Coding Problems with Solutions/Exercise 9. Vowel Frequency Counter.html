Exercise 9. Vowel Frequency Counter

Practice Problem

Write a JavaScript program to count the total number of vowels (a, e, i, o, u) present in a given sentence.

Exercise Purpose

This exercise introduces "Membership Testing." By checking if a character belongs to a specific group (the vowels), you learn how to filter data based on categories. This is a fundamental step toward building text-analysis tools or spam filters.

Given Input
let sentence = "Learning JavaScript is fun!";
Expected Output
Number of vowels: 8
