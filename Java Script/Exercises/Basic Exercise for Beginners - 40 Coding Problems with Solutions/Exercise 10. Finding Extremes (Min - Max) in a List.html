Exercise 10. Finding Extremes (Min - Max) in an Array

Aug-10-2026 | 04:18 PM

Practice Problem

Given an array of integers, find and print both the largest and the smallest numbers.

Exercise Purpose

This exercise explores “Aggregate Functions.” While JavaScript provides built-in methods, understanding how to identify extreme values is critical for data normalization, where you often need to determine the range of a dataset before processing it.

Given Input

const nums = [45, 2, 89, 12, 7];

Expected Output

Largest: 89 Smallest: 2
