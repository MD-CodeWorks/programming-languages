Exercise 8. String Reversal

Practice Problem

Write a JavaScript program that takes a string and reverses it (e.g., "JavaScript" becomes "tpircSavaJ").

Exercise Purpose

This exercise demonstrates string manipulation in JavaScript. Since JavaScript strings are immutable, mastering methods like splitting a string into an array, using array manipulation utilities, or iterating backwards helps build fundamental data manipulation skills.

Given Input
let text = "JavaScript";
Expected Output
Reversed: tpircSavaJ
