Exercise 3. String Indexing and Even Slicing

Practice Problem: Write a JavaScript program to display only those characters which are present at an even index number in a given string.

Exercise Purpose: Understand how strings are indexed in memory using zero-based indexing in JavaScript. In most programming languages, including JS, the first character is at index 0, the second at 1, and so on. Mastering string indexing and loops is vital for string manipulation and data parsing.

Given Input: const str = "JavaScript";

Expected Output:

Original String is JavaScript

Printing only even index chars

J

v

S

r

p
